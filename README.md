# 零号协议：意识迷城

纯前端、单机运行的赛博朋克悬疑 RPG 网页游戏。React + TypeScript + Vite，无后端、无登录、不依赖远程 API，进度只存在浏览器本地（localStorage）。

## 玩法总览

- 7 章主线：序章：死亡证明 → 第一章：不存在的人 → 第二章：被删除的记忆 → 第三章：地下档案馆 → 第四章：AI 的谎言 → 第五章：零号协议 → 终章：意识迷城
- 20 个地点 / 5 个区域，带上锁条件（权限卡、NPC 信任、技能、前置任务）
- 9 名 NPC（各有对话树、信任度、秘密与个人任务）、4 大派系（独立声望，互相影响）
- 30 个任务：主线 14、支线、个人、探索、隐藏各若干，全部有明确完成条件与奖励
- 侦探工作台：20 条证据、关联画布、时间线、3 条关键关联、3 个可证伪假设（含误导线索），选错会给出具体反驳
- 6 种黑客小游戏：电路连接、密码推理、终端入侵、记忆重建、数据解密、资源规划，规则固定可验证，不是随机无解题
- 角色成长：等级/经验/技能点，4 条技能路线 × 8 节点，技能真实影响地点进入、小游戏次数与对话
- 城市模拟：能源、安全、居民信任、AI 控制、抵抗影响力、数据污染 6 项指标，由玩家行动驱动，无后台计时器
- 25 项成就、6 种结局（含隐藏结局），结局由重要选择 + 证据完整度 + 派系声望 + 城市状态共同算分
- 存档：自动存档（刷新后继续）+ 3 个手动存档槽 + 重置

## 建议游玩路线

广场 → 地下交通站 → 地下黑市 → 记忆档案馆 → 旧服务器机房 → AI 管理塔 → 失联者公寓 → 零号核心设施 → 侦探工作台提交最终推理 → 结局回顾页结算。

关键提示：行动次数用完就点“休息”；电网控制室需要黑客路线第 3 个节点；研究中心需要先完成“失联者公寓”任务；核心设施需要哨站的高级权限卡。

## 运行

```bash
npm install
npm run dev
npm run build
```

## 目录结构

```
src/
  game/
    types.ts    # 全部类型定义
    data.ts     # 地点/NPC/派系/物品/技能/证据/任务/章节/背景（数据与 UI 分离）
    engine.ts   # 效果结算、任务判定、成就、结局算分
    store.tsx   # 统一游戏状态、存档槽、时间与移动规则
  components/
    Layout.tsx      # 主界面：顶栏/导航/侧栏/快捷栏
    MainMenu.tsx    # 启动与角色创建
    MapExplore.tsx  # 城市地图、地点探索、NPC 对话
    Systems.tsx     # 任务/背包/技能/角色/派系/城市/成就/章节/结局/存档/设置
    Deduction.tsx   # 侦探推理工作台
    Games.tsx       # 6 种黑客小游戏
```
